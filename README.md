# Clinica Sensory - React + Vite

Projeto migrado de Nuxt para React com TypeScript, Vite, Tailwind CSS v4 e React Router.

## Requisitos

- Node.js 20+

## Setup

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

Aplicacao em `http://localhost:5173`.

## Build de producao

```bash
npm run build
```

## Preview do build

```bash
npm run preview
```

## Lint

```bash
npm run lint
```
